# FBVenom icon assets

The application icon is an SVG layout exported to PNG and a multi-resolution Windows ICO.
The source portrait is kept unchanged and embedded in `icon.svg`; the Facebook mark uses its original vector paths.

- Venom portrait: [Venom 3D Model Head — Wallpapers.com](https://wallpapers.com/png/venom-3d-model-png-tsu80-qv7lp20ai5r10odg.html)
  - Download: https://wallpapers.com/images/high/venom-3d-model-png-tsu80-qv7lp20ai5r10odg.png
  - Character: Marvel's Venom.
- Facebook mark: [Facebook f logo (2019) — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Facebook_f_logo_(2019).svg)
  - Creator: Facebook, Inc.; the Commons source identifies the simple logo as public domain and trademarked.

Retrieved October 5, 2026. App artwork is not an assertion of affiliation with Marvel or Facebook.

The built-in image generator rejected the requested artwork. The installed result uses existing online assets laid out in SVG, rather than generated imagery.
